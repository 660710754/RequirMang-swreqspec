# Feature: ดูเมนูและโปรโมชั่น (Menu & Promotion)
Spec ID: SPEC-MENU-001 | Source: SRS v0.1 ข้อ 3.1 (FR-MENU) | Use case: UC-01
Owner: <ทีม/คน> | Status: Draft v2 | Updated: 2569-09-18
Depends on: - | Reviewed by: -

## Goal
นักศึกษา / ลูกค้า (ผู้ใช้ทั่วไปของระบบเมนูและโปรโมชั่นเดียวกัน) สามารถดูรายการเครื่องดื่ม ราคา รายละเอียด
สถานะสินค้า และโปรโมชั่นของร้าน OWL CHA
รวมถึงค้นหาเครื่องดื่มจากชื่อเมนู
เพื่อใช้ข้อมูลประกอบการตัดสินใจก่อนสั่งซื้อ

## Scope
### In scope
- ดูรายการเครื่องดื่มที่ร้านเปิดขาย
- ดูชื่อ ราคา รายละเอียด และสถานะของเครื่องดื่มแต่ละรายการ
- ค้นหาเครื่องดื่มจากชื่อเมนู
- ดูโปรโมชั่นที่กำลังใช้งานอยู่
### Out of scope
- การกรองเครื่องดื่มตามประเภท (FR-04)
- การสมัครสมาชิก / เข้าสู่ระบบ
- การสร้างคำสั่งซื้อออนไลน์
- การกำหนดจำนวนสินค้าใน Order
- การชำระเงินออนไลน์
- การตรวจสอบสถานะ Order
- การรับแจ้งเตือนเมื่อเครื่องดื่มพร้อมรับ
- การดูและอัปเดต Order ของพนักงาน
- การจัดการเมนู ราคา โปรโมชั่น และสถานะสินค้า
- การดูรายงานยอดขายและสถิติ

## Constraints
- ผู้ใช้ทั่วไปสามารถดูข้อมูลเมนูและโปรโมชั่นได้เท่านั้นไม่สามารถแก้ไขข้อมูลได้
- การค้นหาเมนูค้นหาจากชื่อเมนูแบบ partial และไม่แยกตัวพิมพ์เล็ก/ใหญ่
- เมนูที่หมดสต็อกไม่สามารถกดสั่งได้ แต่ยังแสดงสถานะ “หมด” ให้ผู้ใช้เห็น
- ระบบแสดงเฉพาะโปรโมชั่นที่กำลังใช้งานอยู่เท่านั้น

## Requirements
- FR-01
  ผู้ใช้สามารถดูรายการเครื่องดื่มที่ร้านเปิดขายได้

- FR-02
  ระบบต้องแสดงชื่อ ราคา รายละเอียด
  และสถานะของเครื่องดื่มแต่ละรายการ
  โดยเมนูที่เปิดขายสามารถกดสั่งเครื่องดื่มได้
  และเมนูที่หมดสต็อกจะแสดงสถานะว่า “หมด”

- FR-03
  ผู้ใช้สามารถค้นหาเครื่องดื่มจากชื่อเมนูได้แบบ partial
  โดยไม่แยกตัวพิมพ์เล็ก/ใหญ่
  และเมื่อไม่พบรายการที่ตรงกับคำค้น
  ระบบจะแสดงข้อความว่า “ไม่พบเมนู”

- FR-05
  ระบบต้องแสดงโปรโมชั่นที่กำลังใช้งานอยู่ให้ผู้ใช้เห็นบนหน้าเมนูเดียวกัน
  และจัดเรียงสินค้าที่มีโปรโมชั่นไว้ด้านบนสุด
  หากไม่มีโปรโมชั่นที่กำลังใช้งานอยู่ ระบบจะไม่แสดงส่วนโปรโมชั่น
  และจะคงแสดงเฉพาะเมนูที่ยังเปิดขายอยู่

### Alternative Flow Requirement

- FR-03 / UC-01 Alternative Flow 6a
  เมื่อลูกค้าใช้ช่องค้นหา
  ระบบต้องแสดงรายการเมนูที่ตรงกับคำค้นแบบ partial

### Exception Flow Requirement

- UC-01 Exception Flow 2a
  หากระบบไม่สามารถโหลดข้อมูลเมนูได้
  ระบบต้องแสดงข้อความแจ้งว่าไม่สามารถโหลดข้อมูลได้
  และมีปุ่ม “ลองใหม่” เพื่อเรียกโหลดข้อมูลอีกครั้ง

## Quality Requirements
- NFR-22
  หน้ารายการเมนูและหน้าตรวจสอบสถานะ Order
  ต้องตอบสนองภายใน 2 วินาที (p95)
  ภายใต้จำนวนผู้ใช้พร้อมกัน 100 concurrent users

- NFR-26
  ผู้ใช้ใหม่อย่างน้อย 8 ใน 10 คน
  ต้องสามารถค้นหาเมนู สร้าง Order
  และตรวจสอบสถานะ Order ได้
  โดยไม่ต้องขอความช่วยเหลือ


## Acceptance Criteria
- [ ] AC-MENU-01 (FR-01)

  Given ร้านมีรายการเครื่องดื่มที่เปิดขายอยู่
  When ผู้ใช้เปิดหน้ารายการเมนู
  Then ระบบแสดงรายการเครื่องดื่มที่ร้านเปิดขาย


- [ ] AC-MENU-02 (FR-02)

  Given ระบบมีข้อมูลเครื่องดื่ม
  When ผู้ใช้เปิดหน้ารายการเมนู
  Then ระบบแสดงชื่อ ราคา รายละเอียด
  และสถานะของเครื่องดื่มแต่ละรายการ
  โดยเมนูที่เปิดขายสามารถกดสั่งได้
  และเมนูที่หมดสต็อกจะแสดงสถานะว่า “หมด”


- [ ] AC-MENU-03 (FR-03)

  Given ระบบมีรายการเครื่องดื่มอยู่ในระบบ
  When ผู้ใช้ค้นหาเครื่องดื่มจากชื่อเมนู
  Then ระบบแสดงรายการเครื่องดื่มที่ตรงกับคำค้นแบบ partial
  และหากไม่พบรายการ ระบบแสดงข้อความว่า “ไม่พบเมนู”


- [ ] AC-MENU-04 (FR-05)

  Given ระบบมีโปรโมชั่นที่กำลังใช้งานอยู่
  When ผู้ใช้เปิดหน้าเมนูและโปรโมชั่น
  Then ระบบแสดงโปรโมชั่นที่กำลังใช้งานอยู่บนหน้าเมนูเดียวกัน
  และจัดเรียงสินค้าที่มีโปรโมชั่นไว้ด้านบนสุด

  Given ไม่มีโปรโมชั่นที่กำลังใช้งานอยู่
  When ผู้ใช้เปิดหน้าเมนู
  Then ระบบไม่แสดงส่วนโปรโมชั่น
  และแสดงเฉพาะเมนูที่ยังเปิดขายอยู่


- [ ] AC-MENU-05 (UC-01 Exception Flow 2a)

  Given ระบบไม่สามารถโหลดข้อมูลเมนูได้
  When ผู้ใช้เปิดหน้ารายการเมนู
  Then ระบบแสดงข้อความว่าไม่สามารถโหลดข้อมูลได้
  และมีปุ่ม “ลองใหม่” เพื่อเรียกโหลดข้อมูลอีกครั้ง


- [ ] AC-MENU-06 (NFR-22)

  Given ระบบอยู่ภายใต้จำนวนผู้ใช้พร้อมกัน 100 concurrent users
  When ผู้ใช้เปิดหน้ารายการเมนู
  Then p95 ของเวลาตอบสนองต้องไม่เกิน 2 วินาที


- [ ] AC-MENU-07 (NFR-26)

  Given ผู้ใช้ใหม่จำนวน 10 คน
  When ผู้ใช้ทำภารกิจค้นหาเมนู
  Then ผู้ใช้อย่างน้อย 8 คนต้องสามารถค้นหาเมนูได้
  โดยไม่ต้องขอความช่วยเหลือ


## Assumptions and Open Questions
### Assumptions
- ASM-01
  การค้นหาเมนูทำแบบ partial match โดยไม่แยกตัวพิมพ์เล็ก/ใหญ่

- ASM-02
  เมนูที่สถานะเป็น “เปิดขาย” ยังสามารถกดสั่งเครื่องดื่มได้
  และเมนูที่หมดสต็อกจะแสดงสถานะว่า “หมด”

- ASM-03
  โปรโมชั่นและเมนูแสดงบนหน้าเดียวกัน และสินค้าที่มีโปรโมชั่นจะแสดงที่ด้านบนสุด

- ASM-04
  หากไม่มีโปรโมชั่นที่กำลังใช้งานอยู่ ระบบจะไม่แสดงส่วนโปรโมชั่น
  และจะยังแสดงเฉพาะเมนูที่ยังเปิดขายอยู่

- ASM-05
  เมื่อโหลดข้อมูลเมนูไม่สำเร็จ จะมีเฉพาะปุ่ม “ลองใหม่” เพื่อเรียกโหลดข้อมูลอีกครั้ง
