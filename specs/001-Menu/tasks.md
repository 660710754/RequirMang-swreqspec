# งานย่อยสำหรับ Feature: ดูเมนูและโปรโมชั่น (Menu & Promotion)

## 1. ภาพรวม

งานนี้สืบเนื่องจาก spec.md และ plan.md สำหรับ Feature `SPEC-MENU-001` เพื่อแยกออกเป็นงานย่อยที่สามารถทำทีละส่วนได้ โดยทุกงานต้องอ้างอิงความต้องการจาก FR / AC ที่กำหนดไว้ และไม่เพิ่มฟังก์ชันนอก scope

## 4. การครอบคลุมตาม constraint

| Constraint จาก spec | รายละเอียด | งานที่รองรับ |
|---|---|---|
| ผู้ใช้ทั่วไปสามารถดูข้อมูลเมนูและโปรโมชั่นได้เท่านั้นไม่สามารถแก้ไขข้อมูลได้ | ฟีเจอร์นี้เป็นหน้าดูข้อมูลอย่างเดียว ไม่มีการแก้ไขข้อมูล | T-01, T-02, T-04 |

| เมนูที่หมดสต็อกไม่สามารถกดสั่งได้ แต่ยังแสดงสถานะ “หมด” ให้ผู้ใช้เห็น | ต้องคงสถานะ “หมด” พร้อมปิดใช้งานปุ่มสั่ง | T-02 |
| ระบบแสดงเฉพาะโปรโมชั่นที่กำลังใช้งานอยู่เท่านั้น | ต้องกรองเฉพาะ Promotion ที่ active เท่านั้น | T-04 |

## 5. ข้อสังเกตสำหรับงานต่อไป

- T-01 เสร็จสิ้นแล้วและผ่านการตรวจสอบเบื้องต้น โดยแสดงรายการเมนูพร้อมสถานะและปุ่มสั่งซื้อ/หมดที่สอดคล้องกับ FR-01, FR-02, AC-MENU-01 และ AC-MENU-02
- การทำงานในรอบต่อไปควรเริ่มจาก T-02 ถึง T-05 ก่อน แล้วจึงจัดการ T-06 และ T-07 เป็นการตรวจสอบประสิทธิภาพและ usability
- ทุก task ถูกกำหนดตาม FR/AC ใน spec และไม่มี task ใดที่ขยาย scope เพิ่มนอก requirement ที่ระบุใน spec
