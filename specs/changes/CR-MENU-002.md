# CR-MENU-002: กำหนดผลเมื่อคลิกปุ่มสั่งซื้อ

- สถานะ: อนุมัติ
- วันที่: 2569-10-12
- ฟีเจอร์: SPEC-MENU-001
- อ้างอิงข้อค้นพบ: F-02
- Q ที่ปิด: Q-04
- ผู้เสนอ/ผู้อนุมัติ: ทีม

## คำขอ

กำหนดผลลัพธ์เมื่อผู้ใช้คลิกปุ่ม “สั่งซื้อ” ของเมนูที่เปิดขาย โดยไม่ขยายฟีเจอร์ไปสู่การสร้าง Order ออนไลน์

## การตัดสินใจ

เมื่อผู้ใช้คลิกปุ่ม “สั่งซื้อ” ของเมนูที่เปิดขาย ระบบต้องแสดงข้อความ “ระบบสั่งซื้อออนไลน์ยังไม่เปิดให้บริการ” และต้องไม่สร้าง Order ออนไลน์

## เหตุผล

ทีมตอบ Q-04 เพื่อกำหนดผลลัพธ์ของปุ่มให้ทดสอบได้ โดยยังคงการสร้างคำสั่งซื้อออนไลน์ไว้ใน Out of scope

## ผลกระทบ

- ปรับ FR-02, ASM-02 และ AC-MENU-02 ใน `specs/001-Menu/spec.md` ให้ระบุผลเมื่อคลิกปุ่มสั่งซื้อ และให้ Assumption สอดคล้องกับคำตอบ Q-04
- บันทึก Q-04 เป็นการตัดสินใจที่ปิดแล้วใน spec
- ปรับสถานะ F-02 ใน `specs/001-Menu/rtm.md` เป็น “ทีมตอบ Q-04 แล้ว; รอแก้ Code และ Test”
- ไม่เปลี่ยน Constraint ที่ห้ามสั่งเมนูหมดสต็อก และไม่เพิ่มการสร้าง Order ออนไลน์
- การเปลี่ยนแปลงนี้แก้เฉพาะ Requirement และเอกสารที่เกี่ยวข้อง ยังไม่แก้โค้ดหรือ Automated Tests
