# CR-MENU-001: กำหนดข้อความเมื่อไม่มีรายการเครื่องดื่ม

- สถานะ: อนุมัติ
- วันที่: 2569-10-12
- ฟีเจอร์: SPEC-MENU-001
- ผู้เสนอ/ผู้อนุมัติ: ทีม (อาจารย์อนุญาตให้ทีมตัดสินใจ Requirement เองได้)
- Q ที่ปิด: Q-03

## คำขอ

กำหนดพฤติกรรมของหน้าเมนูเมื่อระบบไม่มีรายการเครื่องดื่มเลย เพื่อไม่ให้แสดงหน้าจอว่างเปล่า

## การตัดสินใจ

หน้าเมนูต้องแสดงข้อความ “ขณะนี้ไม่มีรายการเครื่องดื่ม”

## ผลกระทบ

- เพิ่มข้อกำหนดใน FR-01 และกรณีใน AC-MENU-01 ของ `specs/001-Menu/spec.md`
- ปิด Q-03 โดยบันทึกคำตอบและเหตุผลการตัดสินใจของทีมใน spec
- สร้าง TC-MENU-02-3 เดิมให้ตรวจข้อความที่กำหนด และอ้างอิง FR-01 / AC-MENU-01; การตรวจ traceability ภายหลังย้ายกรณีนี้เป็น TC-MENU-01-1
- ไม่เปลี่ยน scope ส่วนอื่น ไม่แก้โค้ดหรือ Automated Tests ใน CR นี้
