# CR-MENU-004: แสดงเมนูหมดสต็อกเมื่อไม่มีโปรโมชั่น

- สถานะ: อนุมัติ
- วันที่: 2569-10-12
- ฟีเจอร์: SPEC-MENU-001
- อ้างอิงข้อค้นพบ: F-07
- ผู้เสนอ/ผู้อนุมัติ: ทีม

## คำขอ

แก้ข้อกำหนดที่ขัดแย้งกันระหว่าง Constraints กับ FR-05, AC-MENU-04 และ ASM-04 เกี่ยวกับการแสดงเมนูหมดสต็อกเมื่อไม่มีโปรโมชั่น

## การตัดสินใจ

เมื่อไม่มีโปรโมชั่นที่กำลังใช้งาน ระบบไม่แสดงส่วนโปรโมชั่น แต่ยังแสดงรายการเครื่องดื่มทั้งเมนูที่เปิดขายและเมนูที่หมดสต็อก โดยเมนูที่หมดสต็อกต้องแสดงสถานะ “หมด” และปุ่ม “สั่งซื้อ” กดไม่ได้

## เหตุผล

รักษาข้อกำหนดเดิมที่ให้แสดงเมนูหมดสต็อกพร้อมสถานะ “หมด” และป้องกันความขัดแย้งกับเงื่อนไขกรณีไม่มีโปรโมชั่น

## ผลกระทบ

- ปรับ FR-05, AC-MENU-04 และ ASM-04 ใน `specs/001-Menu/spec.md` ให้สอดคล้องกับคำตัดสิน
- คงข้อกำหนดใน Constraints ว่าเมนูหมดสต็อกแสดง “หมด” และไม่สามารถกดสั่งได้
- ไม่เปลี่ยน Task, โค้ด หรือ Automated Tests
