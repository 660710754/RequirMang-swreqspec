# CR-MENU-003: จำกัดขอบเขต NFR ให้ตรงกับ Scope

- สถานะ: อนุมัติ
- วันที่: 2569-10-12
- ฟีเจอร์: SPEC-MENU-001
- อ้างอิงข้อค้นพบ: F-04, F-05
- ผู้เสนอ/ผู้อนุมัติ: ทีม

## คำขอ

ปรับขอบเขต NFR-26 และ NFR-22 รวมถึง Acceptance Criteria ที่เกี่ยวข้อง ให้ครอบคลุมเฉพาะภารกิจและหน้าจอที่อยู่ใน Scope ของฟีเจอร์ดูเมนูและโปรโมชั่น

## การตัดสินใจ

- NFR-26 และ AC-MENU-07 ครอบคลุมเฉพาะภารกิจค้นหาเมนู โดยคงเกณฑ์ผู้ใช้ใหม่อย่างน้อย 8 ใน 10 คนที่ทำได้โดยไม่ต้องขอความช่วยเหลือ
- NFR-22 และ AC-MENU-06 ครอบคลุมเฉพาะหน้าเมนู โดยคงเกณฑ์ p95 ไม่เกิน 2 วินาที ภายใต้ผู้ใช้พร้อมกัน 100 คน

## เหตุผล

การสร้าง Order และการตรวจสอบสถานะ Order อยู่นอก Scope ของฟีเจอร์นี้ จึงไม่ควรเป็นส่วนหนึ่งของเกณฑ์คุณภาพหรือ Acceptance Criteria ของฟีเจอร์

## ผลกระทบ

- ปรับ NFR-26 และ AC-MENU-07 ให้จำกัดเฉพาะภารกิจค้นหาเมนู
- ปรับ NFR-22 และ AC-MENU-06 ให้จำกัดเฉพาะหน้าเมนู
- คงเกณฑ์เชิงปริมาณที่ทีมอนุมัติไว้ตามเดิม
- ไม่เปลี่ยน Task, โค้ด หรือ Automated Tests; T-06 และ T-07 คงสถานะเดิม
