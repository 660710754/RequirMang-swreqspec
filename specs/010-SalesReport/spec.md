# Feature: ดูรายงานยอดขายและสถิติ (Sales Report & Statistics)
Spec ID: SPEC-SALES-REPORT-001 | Source: SRS v0.1 ข้อ 3.10 (FR-SALES-REPORT) | Use case: UC-10  
Owner: <ทีม/คน> | Status: Draft v2 | Updated: 2569-09-18  
Depends on: SPEC-STAFF-ORDER-001, SPEC-ORDER-001 | Reviewed by: -

## Goal
เจ้าของร้าน / ผู้จัดการร้าน (Manager) สามารถดูรายงานยอดขายและสถิติ
ของร้านแยกตามสาขาที่เลือกและตามช่วงวันที่ที่เลือก เพื่อใช้ตรวจสอบข้อมูลยอดขาย
จำนวน Order และเมนูขายดีสำหรับการวิเคราะห์และบริหารร้าน

## Scope
### In scope
- ดูรายงานยอดขาย
- เลือกสาขาที่ต้องการดูรายงาน
- เลือกช่วงวันที่เริ่มและสิ้นสุดที่ต้องการดูรายงาน
- ใช้ค่าเริ่มต้นช่วงวันที่เป็น 7 วันที่ผ่านมา
- แสดงยอดขายรวมตามสาขาและช่วงเวลาที่เลือก
- แสดงจำนวน Order
- แสดงเมนูขายดี
- แสดงข้อมูลในรูปแบบรายงานหรือสถิติ
- เปลี่ยนช่วงเวลาและคำนวณรายงานใหม่
- ตรวจสอบกรณีไม่มีข้อมูลในช่วงเวลาที่เลือก

### Out of scope
- การสร้างหรือแก้ไข Order
- การชำระเงิน
- การจัดการเมนู ราคา และโปรโมชั่น
- การอัปเดตสถานะ Order
- การจัดการผู้ใช้งาน
- การแจ้งเตือนลูกค้า
- การแก้ไขข้อมูลยอดขายย้อนหลังโดย Manager
- การจัดการข้อมูลทางบัญชีหรือภาษี

## Constraints
- ผู้ใช้งานต้องเข้าสู่ระบบและมีสิทธิ์เป็น Manager ของสาขานั้นก่อนเข้าถึงรายงาน
- ระบบต้องคำนวณรายงานจากข้อมูล Order และยอดขายที่มีอยู่ในระบบ
- ช่วงเวลาที่เลือกต้องเป็นช่วงวันที่ที่ถูกต้อง และค่าเริ่มต้นของช่วงวันที่คือ 7 วันที่ผ่านมา
- Manager สามารถดูข้อมูลได้เฉพาะข้อมูลในสาขาที่ตนเองมีสิทธิ์เข้าถึง
- ยอดขายรวมและจำนวน Order คำนวณจาก Order ที่ชำระเงินสำเร็จเท่านั้น
- เมนูขายดีจัดอันดับจากจำนวนชิ้นที่ขายในช่วงเวลาที่เลือก
- หากไม่มีข้อมูลในช่วงเวลาที่เลือก ระบบต้องแสดงข้อความว่าไม่มีข้อมูลสำหรับช่วงเวลานั้น และไม่แสดงตัวเลขใด ๆ
- หากระบบไม่สามารถประมวลผลรายงานได้ ระบบต้องแสดงข้อความเตือนแบบสากล และไม่แสดงข้อมูลรายงานที่ไม่สมบูรณ์
- การคำนวณยอดขายและจำนวน Order ต้องสอดคล้องกับข้อมูลที่บันทึกในระบบ
- รายงานยอดขายควรแสดงผลภายใน 5 วินาทีสำหรับข้อมูลปกติ

## Requirements
- FR-50  
  Manager สามารถเปิดหน้ารายงานยอดขายและสถิติได้

- FR-51  
  Manager สามารถเลือกสาขาและช่วงวันที่เริ่ม-สิ้นสุดที่ต้องการดูรายงานได้
  ค่าเริ่มต้นของช่วงวันที่ที่แสดงคือ 7 วันที่ผ่านมา

- FR-52  
  ระบบต้องคำนวณและแสดงยอดขายรวมตามสาขาและช่วงเวลาที่ Manager เลือก
  ยอดขายรวมคำนวณจาก Order ที่ชำระเงินสำเร็จเท่านั้น

- FR-53  
  ระบบต้องแสดงจำนวน Order ตามช่วงเวลาและสาขาที่เลือก
  จำนวน Order นับเฉพาะ Order ที่สำเร็จ

- FR-54  
  ระบบต้องแสดงข้อมูลเมนูขายดีตามข้อมูล Order ในช่วงเวลาที่เลือก
  เมนูขายดีจัดอันดับจากจำนวนชิ้นที่ขาย

- FR-55  
  เมื่อ Manager เปลี่ยนสาขา หรือเปลี่ยนช่วงเวลา ระบบต้องคำนวณและแสดงรายงานใหม่ตามเงื่อนไขที่เลือก

- FR-56  
  ระบบต้องแสดงข้อมูลรายงานยอดขาย จำนวน Order และเมนูขายดีอย่างถูกต้องตามข้อมูลที่มีอยู่ในระบบ

### Alternative Flow Requirement

- FR-55 / UC-10 Alternative Flow 3a  
  หาก Manager เปลี่ยนสาขา หรือเปลี่ยนช่วงเวลาที่ต้องการดู ระบบต้องคำนวณและแสดงรายงานใหม่ตามสาขาและช่วงเวลาใหม่

### Exception Flow Requirement

- UC-10 Exception Flow 4a  
  หากไม่มีข้อมูลในช่วงเวลาที่เลือก ระบบต้องแสดงข้อความว่าไม่มีข้อมูลสำหรับช่วงเวลานั้น และไม่แสดงตัวเลขใด ๆ

- UC-10 Exception Flow 4b  
  หากระบบไม่สามารถประมวลผลรายงานได้ ระบบต้องแสดงข้อความเตือนแบบสากลเพื่อแจ้งให้ Manager ทราบ และไม่แสดงข้อมูลรายงานที่ไม่สมบูรณ์

## Quality Requirements
- NFR-PERF-02  
  รายงานยอดขายควรแสดงผลภายใน 5 วินาทีสำหรับข้อมูลปกติ

- NFR-SEC-06  
  เฉพาะ Manager ที่ได้รับสิทธิ์ของสาขานั้นเท่านั้นที่สามารถเข้าถึงข้อมูลรายงานยอดขายและสถิติของสาขานั้นได้

- NFR-ACC-01  
  รายงานต้องคำนวณยอดขายและจำนวน Order จากข้อมูลที่ถูกต้องและสอดคล้องกับข้อมูล Order ที่บันทึกในระบบ

## Acceptance Criteria

- [ ] AC-REPORT-01 (FR-50)

  Given Manager มีสิทธิ์เข้าถึงรายงาน  
  When Manager เปิดหน้ารายงาน  
  Then ระบบแสดงหน้ารายงานยอดขายและสถิติ

- [ ] AC-REPORT-02 (FR-51)

  Given Manager อยู่ในหน้ารายงาน  
  When Manager เลือกสาขาและเลือกช่วงวันที่เริ่ม-สิ้นสุด หรือใช้งานค่าเริ่มต้น 7 วันที่ผ่านมา  
  Then ระบบรับข้อมูลที่เลือกและนำไปใช้ในการประมวลผลรายงาน

- [ ] AC-REPORT-03 (FR-52)

  Given ระบบมีข้อมูลยอดขายที่ชำระเงินสำเร็จในสาขาและช่วงเวลาที่เลือก  
  When Manager เปิดรายงาน  
  Then ระบบแสดงยอดขายรวมของช่วงเวลานั้น

- [ ] AC-REPORT-04 (FR-53)

  Given ระบบมี Order ที่สำเร็จในสาขาและช่วงเวลาที่เลือก  
  When Manager เปิดรายงาน  
  Then ระบบแสดงจำนวน Order ของช่วงเวลานั้น

- [ ] AC-REPORT-05 (FR-54)

  Given ระบบมีข้อมูลรายการขายในช่วงเวลาที่เลือก  
  When Manager เปิดรายงาน  
  Then ระบบแสดงข้อมูลเมนูขายดีจากข้อมูล Order และจัดเรียงตามจำนวนชิ้นที่ขาย

- [ ] AC-REPORT-06 (FR-55)

  Given Manager กำลังดูรายงานของสาขาหรือช่วงเวลาหนึ่ง  
  When Manager เปลี่ยนสาขา หรือเปลี่ยนช่วงเวลา  
  Then ระบบคำนวณและแสดงรายงานใหม่ตามสาขาและช่วงเวลาที่เลือก

- [ ] AC-REPORT-07 (FR-56)

  Given ระบบมีข้อมูล Order และยอดขาย  
  When Manager เปิดรายงาน  
  Then ระบบแสดงยอดขาย จำนวน Order และเมนูขายดีให้สอดคล้องกับข้อมูลในระบบ

- [ ] AC-REPORT-08 (UC-10 Alternative Flow 3a)

  Given Manager เลือกสาขาและช่วงเวลาสำหรับรายงาน  
  When Manager เปลี่ยนสาขา หรือเปลี่ยนช่วงเวลา  
  Then ระบบคำนวณและแสดงรายงานใหม่ตามสาขาและช่วงเวลาใหม่

- [ ] AC-REPORT-09 (UC-10 Exception Flow 4a)

  Given ไม่มีข้อมูล Order หรือยอดขายในช่วงเวลาที่เลือก  
  When Manager เปิดรายงาน  
  Then ระบบแสดงข้อความว่าไม่มีข้อมูลสำหรับช่วงเวลานั้น และไม่แสดงตัวเลขใด ๆ

- [ ] AC-REPORT-10 (UC-10 Exception Flow 4b)

  Given Manager เลือกสาขาและช่วงเวลาที่ต้องการดูรายงาน  
  When ระบบไม่สามารถประมวลผลรายงานได้  
  Then ระบบแจ้งให้ Manager ทราบผ่านข้อความเตือนแบบสากล และไม่แสดงข้อมูลรายงานที่ไม่สมบูรณ์

- [ ] AC-REPORT-11 (NFR-SEC-06)

  Given ผู้ใช้งานไม่มีสิทธิ์ Manager ของสาขานั้น  
  When ผู้ใช้งานพยายามเปิดหน้ารายงานยอดขาย  
  Then ระบบไม่อนุญาตให้เข้าถึงข้อมูลรายงานของสาขานั้น

- [ ] AC-REPORT-12 (NFR-ACC-01)

  Given ระบบมีข้อมูล Order และยอดขายที่ถูกบันทึกไว้  
  When Manager เปิดรายงาน  
  Then ยอดขายและจำนวน Order ที่แสดงต้องสอดคล้องกับข้อมูลที่บันทึกในระบบ

## Assumptions and Open Questions

### Assumptions
- ASM-01  
  ผู้ใช้งานที่เข้าถึงรายงานเป็น Manager ที่เข้าสู่ระบบและได้รับสิทธิ์แล้ว

- ASM-02  
  ระบบมีข้อมูล Order และข้อมูลยอดขายที่สามารถนำมาประมวลผลได้

- ASM-03  
  Manager สามารถเลือกสาขาและช่วงวันที่เริ่ม-สิ้นสุดสำหรับดูรายงานได้

- ASM-04  
  ค่าเริ่มต้นของช่วงวันที่สำหรับรายงานคือ 7 วันที่ผ่านมา

- ASM-05  
  ยอดขายรวมคำนวณจากข้อมูลการขายของ Order ที่ชำระเงินสำเร็จเท่านั้น

- ASM-06  
  จำนวน Order คำนวณจาก Order ที่สำเร็จเท่านั้น

- ASM-07  
  เมนูขายดีพิจารณาจากจำนวนชิ้นที่ขาย และจัดเรียงจากมากไปน้อย

- ASM-08  
  หากไม่มีข้อมูลในช่วงเวลาที่เลือก ระบบจะแสดงข้อความว่าไม่มีข้อมูลสำหรับช่วงเวลานั้น และไม่แสดงตัวเลขใด ๆ

- ASM-09  
  หากระบบไม่สามารถประมวลผลรายงานได้ ระบบจะแสดงข้อความเตือนแบบสากล

- ASM-10  
  รายงานนี้แยกตามสาขา และ Manager จะเห็นข้อมูลเฉพาะสาขาที่ตนเองมีสิทธิ์เข้าถึง

- ASM-11  
  รายงานยอดขายควรแสดงผลภายใน 5 วินาทีสำหรับข้อมูลปกติ

### Open Questions
- ไม่มี
